## 📌 Proje Hakkında

Reklam ajansları için geliştirdiğim otomasyon sistemi. Özel günlerden 5 gün önce otomatik olarak 3 adet hazır post tasarımı üretip, 5 adet de yaratıcı post fikri öneriyor. Ajansların içerik planlamasını kolaylaştıran akıllı bir planlama aracı.
